# ACM Mentor Program Portfolio Project

This repository implements a complete teaching package for mentoring beginners through HTML, CSS, and React by building a portfolio website.

## What is included

- `portfolio-incomplete/`: a basic starting point for your portfolio
- `curriculum/`: coming soon, a set of instructions for how to proceed


# HELP

## How do I start the app?

```bash
cd react-portfolio
npm install
npm run dev
```

After the first run simply type:

```bash
npm run dev
```
